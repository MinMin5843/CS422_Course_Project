# Computer Science Outcomes & Job Posting Competitveness

## Project Overview
This project has two main tasks:

* **Task 1:** Predict whether a computer science student will be employed or unemployed based on their academic performance, skills, and interests using the Computer Science Students Career Prediction dataset.
* **Task 2:** Predict how competitive a job posting is (low/medium/high difficulty) using the Tech Jobs, Salaries, and Skills (Version 1) dataset.

## How to run the program:

1. Create and activate a virtual environment.
2. Install the dependencies with the following command: 

    ```bash 
    pip install -r requirements.txt
3. Run Task 1 with the following command:
    
    ```bash
    python main_task1.py
4. Run Task 2 with the following command:
    
    ```bash
    python main_task2.py
